# Swiftlet starter

Dispatch a method and request path against a table of literal and parameterized routes. Return a matched template and the methods a client can use.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Swiftlet** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
200
405
404
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/swiftlet) · [View the release](https://github.com/Rahulchaube1/blyx-swiftlet/releases/tag/v0.1.0)
